# Mod 获取中心 / 安装流程原型

这是第二阶段 UI 方向的静态 HTML 原型，用来评审信息架构和交互流程，不是正式 WPF 实现。

## 评审重点

- 左侧导航：`获取`（发现 Mod、下载队列、本地仓库）与 `管理`（已安装、冲突与依赖、配置档案）。
- 发现页：左侧结果列表，右侧详情；详情固定头部，下面分 `简介 / 文件 / 依赖`。
- 下载与安装是两个独立动作：详情页按钮是“下载到本地仓库”，下载完成后行内出现“已入库 + 安装”。
- 安装前弹窗展示目标目录、文件数、覆盖项、缺失前置和冲突，确认后才部署。
- 来源统一展示：Nexus、Thunderstore、GitHub、本地导入。

## 运行

直接用浏览器打开 `prototype.html`，无外部依赖、无构建步骤。

## 约束

- 本目录只是设计资料，不参与 `ModManager.sln` 构建。
- 正式 WPF XAML 必须等 UI 方向获得明确批准后再改。
